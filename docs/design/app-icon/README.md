# 猫耳任务手账图标

用户于 2026-10-19 确认奶油白＋鼠尾草绿方向并授权替换应用图标。

- `approved-presentation.png`：已确认的设计效果图（内置图像生成工具制作）。
- `approved-sage-concept.png`：绿色原始概念图。
- `launcher-sage-preview.png`：正式矢量图标的预览。
- `launcher-sage.svg`：正式图标可编辑矢量源，与 Android 前景使用同一组路径。矢量版简化阴影与细节，保留猫耳、三枚装订环和大勾号。
- `app/src/main/res/drawable-v24/ic_launcher_foreground.xml`：Android 彩色前景。
- `app/src/main/res/drawable/ic_launcher_background.xml`：浅鼠尾草绿背景。
- `app/src/main/res/drawable/ic_launcher_monochrome.xml`：系统主题图标线稿。

配色：背景 #E4EBDD；封面 #FFF8EA；轮廓 #304F3D；勾号 #86AA83；耳朵 #F4B99A。

前景已居中并预留裁切空间，圆形与圆角方形由桌面启动器裁切。应用 minSdk 为 26，所有支持的 Android 版本使用 adaptive icon。未实现应用内切换图标功能，该功能留待后续。
