# v1.5 未完成订单老板标记与自动置顶

账号信息列表按老板分组：存在未完成短期单，或未到期的托管服务（含尚未开始）时，老板姓名前显示高亮 PendingActions 图标，并显示“进行中 · X 单”和高亮边框。今天的托管任务打完不会提前解除整项服务的标记。

存在未完成订单的老板统一置顶，各组按不可变的老板编号排序。随着现有订单仓储流更新，部分结单继续保留标记，最后一单结单或托管到期后自动清除标记并恢复编号排序。没有改写老板编号、手工排序或数据库 schema。

实现：AccountsViewModel 合并老板、托管和未完成短期订单流，推导 OwnerSummary.unfinishedOrderCount；AccountsScreen 使用该计数显示标记。

验证：160 项单元测试、11 项账号列表与导航设备测试全部通过；lintDebug、assembleDebug、git diff --check 通过。单元回归涵盖多单部分完成、最后一单完成后的响应式恢复、托管未开始/进行中/到期；界面回归确认结单后图标和提示消失。Android 16 模拟器覆盖，无实体设备覆盖。
