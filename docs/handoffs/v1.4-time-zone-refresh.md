# v1.4 时区与刷新设置

模板编辑和新建订单共用时区选择器；初始仅提供中国时间 Asia/Shanghai 与美国东部时间 America/New_York。纽约时区使用 Java ZoneId 规则，自动处理夏令时。

用户可以搜索系统支持的时区、填写显示名称、添加或删除候选项。列表持久化保存在本地，两处入口共用；删除当前候选项不改写表单、模板或订单已保存的时区。无效时区和重复时区无法添加。

两处刷新编辑区只显示每日刷新；移除每周刷新星期、时间和相关说明。模板列表、导入预览、订单详情也移除每周刷新展示。既有数据库和模板文件格式保持兼容，历史订单快照及每周任务原有记录不改写。

验证：158 项单元测试通过；TimeZoneSelectorTest 与 TemplateLibraryUiTest 共 8 项设备测试通过；assembleDebug、lintDebug、git diff --check 通过。设备为 Android 16 模拟器，无实体设备覆盖。
