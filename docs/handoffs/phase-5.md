## 接手修复

1. 修复 Kotlin 2.2 与 AndroidX Hilt Worker 处理器不兼容导致的构建失败，使用标准 WorkerFactory 并保留现有 Hilt 依赖注入。
2. 串行化两个并发备份/恢复的独占操作；覆盖全部仓库事务和附件发布，阻止跨恢复代次的旧写入。
3. 恢复的破坏性阶段和提醒协调纳入不可取消区；等待 WorkManager 调度持久提交后才能清除恢复证据。调度失败保留日志并锁定访问，供下次启动重试。
4. 校验整数范围、计数器、同订单/期次的收款更正关系和余额，损坏文件在替换前拒绝。
5. 修复提醒自取消、重复刷新推迟任务、权限异常及通知入口导航问题。
6. 增加启动就绪屏障、恢复遮罩和导航重建，修复 UI 测试启动等待及不合法测试夹具。
