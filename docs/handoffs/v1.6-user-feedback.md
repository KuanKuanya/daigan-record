# v1.6 用户反馈修复

日期：2026-10-19。对应 [用户反馈记录](../user-feedback-issues.md) 的 UF-001 至 UF-004。

## 实现范围

- 订单详情右上角新增“管理”入口，展开后可选择“修改日期”、删除或作废。托管订单可选择期次，短期订单可修改或清除截止日期。日期更正不创建新期次，不改价格和收款；禁止期次重叠、颠倒期次先后顺序或将已有打卡/进度移出服务期限。有发生记录时不能移动本期开始日期，以避免每隔若干天的起算点和历史窗口被改写。
- 无打卡、进度、附件、收款、批量操作引用及续期记录的误建订单，经过确认可删除。删除在事务中依次清理建单操作身份、任务、期次和订单，避免外键残留。
- 已有业务记录的订单可确认作废。保留历史订单、期次、任务、附件、收款和更正审计；停止任务与提醒，取消剩余待收款，不计入有效接单数，不再阻止老板或账号归档。实际收款继续计入收入，既有流水仍可更正或作废。作废不可撤销，界面明确提示；账号订单列表标记“已作废”。
- 老板详情的已归档账号默认收起，显示数量，可点击展开查看、恢复，并保存当前老板的展开状态。
- 任务及模板增加 MONTHLY / monthDay，固定日号为 1–31；无该日的月份跳过。使用 M:yyyy-MM-dd 发生键，按游戏时区与每日刷新判断游戏日，服务期限外不生成任务。涵盖今日任务、订单日历、历史补录、提醒、续期快照、模板交换与建单状态恢复。
