# v1.3 订单详情补打卡修复

根因：详情日历复用了仅允许当前任务窗口的今日打卡接口，历史日期的 occurrenceKey 因此被识别为过期数据并拒绝。

修复：增加日历专用完成回调，显式传入期次、任务、选中日期和发生记录标识，通过已有 setHistoricalCompletion 接口完成或取消打卡。每周任务保留原始周窗口标识。今日任务原有刷新校验保持有效，历史补录仍由仓储校验服务期限、任务重复规则、归档状态和未来日期限制。

验证：OrderDetailScreenTest 与 HostingOccurrenceTest 共 24 项设备测试全部通过；lintDebug、assembleDebug、git diff --check 通过。新增过去日期日历点击测试，确认使用补录回调且不触发今日保存接口。测试设备为 Android 16 模拟器。

交付：artifacts/v1.3/daigan-record-v1.3-debug.apk；内部版本 1.3，versionCode 4。
