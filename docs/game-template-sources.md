# 游戏模板内容来源与核实记录

核实日期：2026-10-18。本文记录 Phase 4 内置模板（重返未来：1999、鸣潮、通用模板）中
每一条规则或名称的来源、适用区服与仍未核实的部分。

**结论先行：** 两款游戏的“每日刷新时刻”和“每周刷新日”有官方或官方公告转载作为依据；
任务条目名称来自游戏内/社区常用称呼，具体开放条件和活动轮换可能随版本变化。所有时刻、
名称和数值在应用内都是**可编辑的模板默认值**，不是运行时从网络获取的官方数据。
数值目标（如“消耗活性 100”）是可编辑示例，不是官方数值。

## 3. 通用模板

内置模板：`app/src/main/assets/templates/generic.json`

不针对任何具体游戏，不代表任何官方规则。它同时演示：

- 每日、每周、指定星期（周六/周日）、每隔 2 天和一次性（短期单）五种任务；
- 勾选与数值进度、起始值/目标值/单位；
- 可直接编辑的时区、每日/每周刷新时间。

## 4. 应用内的处理方式

- 模板的 `gameVersionNotes` 明确写出整理日期、版本区间和“条目为常用称呼”“数值目标为
  可编辑示例”的说明。
- 模板只是新建订单时的默认值；订单会复制自己的任务与刷新快照，之后修改模板不会改写
  历史日期归属。
- 无法核实的时刻/区服差异通过可编辑字段暴露，而不是伪造“官方已核实”的数据。
- 不联网、不内置“模板商店”，文件导入导出只走系统文档选择器。

## 5. 已知缺口

- 没有逐条核实每个任务在当前版本是否仍然存在；用户可自行增删。
- 深眠域的双周节奏、活动限时任务等未被模板模型表达；`WEEKLY` / `EVERY_N_DAYS` 只提供
  近似或用户自定义能力。
- 若官方调整刷新时刻，模板不会自动更新；需要用户编辑或重新导入。
